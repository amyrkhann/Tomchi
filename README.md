# JET DELIVERY — автоматическая проверка по карте

Версия использует 2GIS Geocoder API: адрес клиента превращается в координаты, затем сервер рассчитывает расстояние до каждой из 5 точек отправления. Если расстояние <= настроенного радиуса хотя бы одной точки, доставка бесплатная.

2GIS официально поддерживает прямое геокодирование адреса в координаты через Geocoder API. Для API нужен ключ. Документация: https://docs.2gis.com/api/search/geocoder/overview

## 1. Получить ключ 2GIS
Создайте API key в 2GIS Platform Manager и включите Geocoder API.

## 2. Запуск
Нужен Node.js 18+.

Linux/macOS:
export DGIS_KEY="ВАШ_КЛЮЧ_2ГИС"
export ADMIN_TOKEN="СЛОЖНЫЙ_ПАРОЛЬ"
node server.js

Windows PowerShell:
$env:DGIS_KEY="ВАШ_КЛЮЧ_2ГИС"
$env:ADMIN_TOKEN="СЛОЖНЫЙ_ПАРОЛЬ"
node server.js

Открыть:
http://localhost:3000

Админ:
http://localhost:3000/admin

## 3. Настроить бесплатную зону
В админке у каждой из 5 точек задайте реальный радиус бесплатной доставки в метрах.

Например:
Абылай Хана 24 → 1000
Абылай Хана 34 → 1000
...

Сейчас стоит 1500 м как стартовое значение — это НЕ утверждение вашей реальной бесплатной зоны. Его нужно заменить на ваш фактический радиус.

## Как работает
Клиент вводит любой адрес.
↓
2GIS находит здание и его координаты.
↓
Сервер получает координаты 5 точек отправления.
↓
Считает расстояние до каждой точки.
↓
Если хотя бы одна точка в пределах её радиуса → 0 ₸.
Иначе → "Ваш адрес не входит в бесплатную зону доставки."

## Важно
Это настоящая географическая проверка по координатам, но зона сейчас задана как круг вокруг каждой точки. Если ваша бесплатная зона имеет неправильную форму (например, границы по улицам), следующий шаг — сделать polygon/полигон зоны на карте в админке. Тогда проверка будет "точка внутри полигона", а не по радиусу.
